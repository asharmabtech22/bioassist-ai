# BioAssist AI

BioAssist AI is an open-source toolkit designed to help biotechnology and bioinformatics students and researchers use AI to accelerate scientific research and learning.

## Features

- 📚 Literature review assistance
- 📝 Research paper summarization
- 🧬 FASTA sequence utilities
- 🔬 Experimental design support
- 📖 Scientific writing assistance
- 🎓 Learning resources for biotechnology and bioinformatics

## Planned Features

- Sequence analysis tools
- Gene annotation assistant
- PubMed integration
- BLAST workflow helper
- Streamlit web interface

## Installation

```bash
git clone https://github.com/asharmabtech22/bioassist-ai.git
cd bioassist-ai
pip install -r requirements.txt
```
